# Cartoon Studio Android
A clean Jetpack Compose Android editor prototype with directly connected controls.

Open the project in Android Studio, sync Gradle, and run on an Android device/emulator.
MainActivity.kt contains the working UI interactions, browser-free speech via Android TextToSpeech,
character/background libraries, animation/expression controls, dialogue, scenes, and timeline controls.

Note: real AI image generation, true character rigging, MP4/4K rendering, and chroma-key image processing
require additional engines/libraries/backend services; this project intentionally keeps the first build stable.
